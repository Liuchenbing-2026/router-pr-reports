Where are we now?

基础能力已陆续合入，精确选路和预测调度仍在推进；多副本恢复与完整 API 兼容还有明显缺口。这里把官方规划、主干实现、开放 PR 和我们的交付放在一张图里。Foundational capabilities have landed. Exact routing and predictive scheduling are still advancing; multi-replica recovery and full API parity have substantial gaps. This report connects the plan, main-branch code, open PRs and our contribution.
